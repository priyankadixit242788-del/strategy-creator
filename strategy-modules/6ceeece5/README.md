For each NIFTY 50 stock and trading date, this screener selects the earliest available 5-minute candle and returns it only when its high is above and its low is below each of SMA20, SMA50, and SMA200. The range is calculated as high minus low. By default it scans the last 10 trading sessions with candles; `/scan` accepts inclusive `from_date` and `to_date` parameters, limited to a 90-calendar-day span. It returns one row per matching stock and date, ordered newest date first and then by range descending. The default limit of 1 is applied independently to each date; `limit=0` disables the cap. `sort_by` and `sort_dir` can override the within-date ordering. The response includes the applied date range, available data bounds, and trading dates.
