For each of the top 300 highly liquid stocks and trading date, this screener selects the earliest available 5-minute candle and returns it only when its high is strictly above and its low is strictly below each of the stored `sma20`, `sma50`, `sma200`, and `superTrend` values. Equality or a missing indicator does not qualify, and later candles cannot qualify in place of the first candle. The range is calculated as high minus low.

The liquidity universe is ranked independently for each scan date by total traded value (`sum(close * volume)`) over the preceding 20 trading sessions with 5-minute candles in `stock__candles_data`. It uses only dates before the scan date, including history before `from_date`, to avoid look-ahead. Only stocks with positive traded value qualify; ties are broken by symbol ascending. Fewer than 300 stocks can qualify when history is limited; no prior history produces no matches. `/scan` exposes `universe_size` (default 300, range 1–300) and `liquidity_lookback` (default 20 trading sessions, range 1–90). This requires the candle table's `close` and `volume` columns in addition to the existing indicator columns. Liquidity ranking is performed in ClickHouse and matches are fetched one scan date at a time.

By default it scans the last 10 trading sessions with candles; `/scan` accepts inclusive `from_date` and `to_date` parameters, limited to a 90-calendar-day span. It returns one row per matching stock and date, ordered newest date first and then by range descending. The default limit of 1 is applied independently to each date; `limit=0` disables the cap. `total` counts all matches before the per-date cap. `sort_by` and `sort_dir` can override the within-date ordering. The response includes the applied date range, available data bounds, and trading dates for the result page's date-range filter. The confirmed table layout remains Symbol, Date, High, Low, range, and Candle time, with symbol search, column sorting, and Top N only pagination; SuperTrend is a condition, not an additional output column.
